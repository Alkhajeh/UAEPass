# UAE PASS SDKs

Use either SDK independently. The Flutter SDK provides UAE PASS sign-in and opens signing approval. The Node SDK handles authorization code exchange, qualified and advanced PDF signing, and signature verification on the backend.

## SDKs

| SDK | Supported platforms | Get started |
| --- | --- | --- |
| Flutter | Android, iOS, Web | [Integration guide](packages/flutter/README.md) · [Example app](packages/flutter/example/README.md) |
| Node.js | Backend, Node.js 22+ | [Integration guide](packages/node/README.md) · [PDF signing demo](packages/node/example/README.md#browser-signing-demo) |

## Optional end-to-end staging demo

Run the Flutter example and Node staging server from the same checkout to try sign-in with code exchange or sign a sample PDF. [Node server setup](packages/node/example/README.md) · [Flutter backend setup](packages/flutter/example/README.md#optional-backend-exchange)
