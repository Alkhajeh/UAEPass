# UAE PASS SDKs

The `uaepass` Flutter plugin supports Android and iOS. See the [Flutter package](packages/flutter/) for installation and integration instructions and the [example app](packages/flutter/example/) for a working project.

## Develop the Flutter package

Run Flutter commands from the package directory.

```sh
cd packages/flutter
flutter pub get
flutter test
```

Run the example from its own directory with an Android or iOS device selected.

```sh
cd packages/flutter/example
flutter pub get
flutter run
```

Run `flutter pub publish --dry-run` from `packages/flutter/` to preview the pub.dev package.
